How it works:
1. Click START CAMERA.

3. The system checks the prediction continuously.
4. After the same letter is detected for 5 consecutive frames, it is confirmed.
5. The confirmed letter is displayed.
6. The letter is automatically spoken only once.
7. The same letter will NOT be spoken again until a different letter is confirmed.
